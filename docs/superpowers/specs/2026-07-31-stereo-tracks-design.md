# Раздельные дорожки «Я/Они»

**Дата:** 2026-07-31
**Статус:** утверждён

## Цель

Убрать кашу при одновременной речи и дать структуру диалога: микрофон и
системный звук записываются раздельно и транскрибируются независимо.

## Запись

Встречи пишутся в **стерео-WAV**: левый канал — микрофон, правый — монитор
дефолтного аудиовыхода. Один файл на встречу, `list`/`play`/`rename`
работают без изменений. Дорожки не смешиваются; размер файла удваивается
(64 КБ/с). Диктовка остаётся моно.

Микшер: вместо суммирования пишет кадры (по сэмплу с каждой дорожки),
выравнивание по `min()` длин очередей как раньше; при финализации хвосты
дополняются тишиной в недостающих каналах.

## Транскрипция

- Число каналов WAV выбирает путь: 1 — прежний плоский текст, 2 — диалог.
- Каналы распознаются независимо (одна модель, два состояния), каждый со
  своим VAD-префильтром.
- VAD вырезает тишину и сдвигает время, поэтому фильтр возвращает таблицу
  соответствия «время в отфильтрованном → время в оригинале»; таймстемпы
  сегментов whisper отображаются обратно в реальное время записи.
- Сегменты обоих каналов сливаются сортировкой по началу; каждая строка
  подписывается: `Я:` (микрофон) / `Они:` (системный звук). Пустые
  сегменты пропускаются; пустой канал не даёт строк.

```
Я: Что я хотел спросить...
Они: Возможно, это связано с тем, что...
```

## Совместимость

Старые моно-записи транскрибируются по прежнему пути. Сводной моно-дорожки
для новых встреч больше нет.

## Тестирование

Юниты: микшер (интерливинг, хвосты), таблица соответствия времени, слияние
диалога. Вручную: транскрипция старой моно-записи (регресс) и новой
стерео-записи с речью в системном канале.
